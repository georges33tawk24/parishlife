## A. Summary

- **Overall: pass, with 7 known bugs and none critical.** Backend: `dotnet test ParishLife.slnx` exit 0, with **unit 98 of 98** and **integration 531 passed, 3 skipped (the known failures), 0 failed of 534**. End-to-end: `E2E_CHANNEL=chromium npm run e2e` **42 of 42 passed** in 6.0 min (it took about 14 min before, waiting on outside hosts). That includes the 4 known failures, which Playwright counts as passed while they fail as expected. "public pages load signed out" now passes. Each test that proves a bug is marked as a known failure (xUnit `[KnownFailureFact]`, run with `QA_KNOWN_FAILURES=1`; Playwright `test.fail`). The suites stay green, and each marker flips the day its bug is fixed.
- **The e2e harness is fixed and offline.**
  - "public pages load signed out" now passes without trusting the local certificate. The runner reads the test host's public-key hash, and Chromium accepts only that certificate (`--ignore-certificate-errors-spki-list`).
  - The suite no longer needs the internet. The test host answers Turnstile siteverify itself, with Cloudflare's dummy-key rules. The browser gets a stand-in widget, a blank Google page, and a refusal for any other outside host.
- **Most serious findings:**
  1. Sign-in timing tells which email addresses have accounts: about 50 ms for a real address against 1 ms for an unknown one. Medium, to 03.
  2. Published photos keep their GPS metadata. Medium; owner decision C3.
  3. There is no daily cap on code emails to one address. Low now; Medium once Resend is on.
- **Proved working:**
  - A signed-in stranger with MFA gets nothing from another account's parish, archdiocese, note or session, across 599 calls (every signed-in endpoint except sign-out). 03's sweep already covered anonymous callers.
  - Every unsafe endpoint refuses a request without the CSRF token.
  - The whole account life works in the browser: age box, sign-up, email code, reset from a second device, data copy and closure.
  - axe: 230 of 230 page states are clean.
  - Load: 0 errors at ten times the assumed pilot load.
