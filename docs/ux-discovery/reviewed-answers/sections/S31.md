### S31.01

**Question:** Which interactions should save immediately, autosave a draft or require explicit Save? Define consistent rules for records, preferences, attendance grids, plans and long request forms.

**Disposition:** Change — adopt the explicit behavior below, with new details proposed for review. **Release:** First release (retained module/design scope).

**Authority/evidence:** Proposed recommendation. Source: [docs/ux-discovery/complete-questionnaire-answers.md:9545](../../complete-questionnaire-answers.md). Canonical question: [questionnaire](../../questionnaire.md). New specification material is proposed unless explicitly identified as a recorded owner direction.

**Proposed answer:** Use explicit Save for office records, service plans and settings changes with consequential scope; autosave permitted long-form drafts without submitting them.
